# 초기화 후 입력과 메시지 제거

## 사전 조건
새 페이지에서 시작하며, 이름·이메일·약관 동의를 입력해 등록을 완료한 상태다.

## Steps
1. 초기화 버튼을 누른다

## Expected
이름과 이메일 입력값이 빈 값으로 바뀌고 약관 동의 체크가 해제되며 오류 메시지와 완료 메시지가 표시되지 않는 상태가 된다.
