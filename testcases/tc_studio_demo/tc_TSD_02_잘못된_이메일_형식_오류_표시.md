# 잘못된 이메일 형식 오류 표시

## 사전 조건
새 페이지에서 시작한다.

## Steps
1. 이름에 "테스터"를 입력한다
2. 이메일에 "invalid"를 입력한다
3. 등록 버튼을 누른다

## Expected
이메일 형식 오류 메시지가 표시된다.
- "이메일 형식을 확인하세요."
