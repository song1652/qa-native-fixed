# 정상 회원 등록 완료 표시

## 사전 조건
새 페이지에서 시작한다.

## Steps
1. 이름에 "테스터"를 입력한다
2. 이메일에 "qa@example.test"를 입력한다
3. 약관 동의를 체크한다
4. 등록 버튼을 누른다

## Expected
등록 완료 메시지가 표시된다.
- "등록 완료: 테스터 (qa@example.test)"
