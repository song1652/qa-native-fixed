# 인증 API 실패 시 에러 메시지 표시 검증 (실패 상세 화면 데모용)

## 사전 조건
로그인 폼이 렌더링된 상태
(이 그룹은 실패 상세(Failure Inspector) 화면을 직접 확인해보기 위한
데모용입니다 — 실제 고객 사이트 대신 자체 완결된 페이지를 쓰고,
인증 API가 500을 반환하도록 의도적으로 구성했습니다)

## Steps
아이디와 비밀번호 입력 필드에 값을 입력한다
"로그인" 버튼을 클릭한다
인증 요청이 완료될 때까지 기다린다

## Expected
"로그인에 실패했습니다. 다시 시도해주세요." 에러 메시지가 화면에 표시된다
