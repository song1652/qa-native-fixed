# README 화면 캡처

- 촬영 날짜: **2026-11-04**.
- 기준 구현: `qa-native-fixed`의 현재 웹 대시보드. Native App 화면을 재사용하지 않았습니다.
- 도구: Playwright Chromium, **1920 × 1080**, 배율 1.
- 환경: 실제 대시보드 HTTP 서버를 임시 프로젝트 데이터에 연결해 촬영했습니다. API 응답 주입은 사용하지 않았습니다.
- 대시보드·빠른 실행·파이프라인은 실행 데이터·생성 코드가 없는 초기 상태입니다. 성공 실행의 증거가 아닙니다.
- TC 라이브러리는 저장소의 자동화 테스트용 Excel fixture를 `web-qa-demo` 스위트로 실제 가져온 6개 예시 케이스입니다. 셀의 결과 값도 fixture 내용이며 실제 실행 결과가 아닙니다.
- 원본 프로젝트의 TC·설정·실행 이력을 변경하지 않았습니다. 사용자 계정·연결 토큰·비공개 기획 정보는 포함하지 않았습니다.
