# TC-IMPSET-01: 이메일 형식 오류 시 안내 문구 표시

## 전제조건
- 새 페이지에서 시작

## 단계
1. 이름에 "테스터" 입력
2. 이메일에 "invalid" 입력
3. 등록 버튼 선택

## 기대결과
- 이메일 형식 오류 안내가 표시된다.
반영 이력에서 되돌릴 수 있습니다.
