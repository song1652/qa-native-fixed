# Import 기능의 TC 스튜디오 통합 구현 계획

> 실행 방식: 기존 worktree에서 병렬 에이전트로 독립 변경을 수행하고 통합 검증한다. 사용자 승인: 2026-09-30 ‘통합방향으로 개발하고 문서들도 업데이트’.

**목표:** 기존 Import 기능을 TC 스튜디오 가져오기·이력·내보내기에 통합하고 별도 화면을 제거한다.

**설계:** 라이브러리를 편집 원본으로 사용한다. 기존 md 반영·롤백 엔진, API 호환, 저장 데이터는 유지한다. 새로운 Excel→라이브러리 반영은 별도 작업으로 변경 미리보기와 템플릿 포함 복구를 제공한다.

## 제약과 결정

- 기존 브랜치 feat/tc-studio-phase1에서 커밋하고 push하지 않는다.
- TDD: 기능별 회귀 테스트 → 실패 확인 → 구현 → 통과 확인.
- 내부 case_id와 외부 source_tc_id를 구분하며 원본 태그를 보존한다.
- 이미 배정된 md ID는 바꾸지 않는다. 외부 ID를 기존 md와 연결할 때 내용 비교·충돌 처리를 유지한다.
- 가져온 모든 TC는 라이브러리에 저장한다. md의 승인·검증·문구 확인·그룹 조건은 유지한다.
- 가져오기 반영 전에 원본 업로드와 스위트 변경을 검사한다. 작업 복구는 이후 편집을 덮어쓰지 않는다.
- 이력은 Excel→라이브러리, 기존 Excel→md, TC→md를 구분한다.
- 기존 Import 전용 메뉴·자산 제거와 /import-studio 이동은 회귀 통과 후 적용한다.
