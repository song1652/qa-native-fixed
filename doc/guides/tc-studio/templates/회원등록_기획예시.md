# 회원 등록 기획 예시

이 문서는 TC 스튜디오의 입력 방법을 연습하기 위한 가상의 기획 정보입니다.
실제 서비스에 적용하기 전에는 서비스 기획서와 디자인의 내용을 사용하세요.

## 화면과 입력 항목

- 화면 이름: 회원 등록
- 이름 입력란: 필수 입력
- 이메일 입력란: 이메일 형식으로 입력
- 약관 동의: 필수 선택
- 버튼: 등록, 초기화

## 조건과 기대 동작

1. 이름을 비워 두고 등록 버튼을 누르면 "이름을 입력하세요." 오류 메시지가 표시된다.
2. 이름에 "테스터", 이메일에 "invalid"를 입력하고 등록 버튼을 누르면 "이메일 형식을 확인하세요." 오류 메시지가 표시된다.
3. 이름에 "테스터", 이메일에 "qa@example.test"를 입력하고 약관에 동의하지 않은 채 등록 버튼을 누르면 "약관에 동의하세요." 오류 메시지가 표시된다.
4. 이름에 "테스터", 이메일에 "qa@example.test"를 입력하고 약관 동의를 선택한 뒤 등록 버튼을 누르면 "등록 완료: 테스터 (qa@example.test)" 완료 메시지가 표시된다.
5. 정상 등록 후 초기화 버튼을 누르면 이름과 이메일이 빈 값으로 바뀌고, 약관 동의가 해제되며, 오류 메시지와 완료 메시지가 표시되지 않는다.

## TC 작성 조건

- 각 TC는 회원 등록 페이지를 새로 연 상태에서 시작한다.
- 우선순위는 P1이다.
- 위에 명시한 기능과 조건을 기준으로 작성한다.
- 화면 문구는 이 문서의 예시다. 실제 화면이나 확정 디자인에서 확인하기 전에는 추정으로 관리한다.
